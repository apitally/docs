## Requirements

Requires Node.js 20.6+ or Bun 1.2.0+.

## Installation

<CodeGroup>
```shell npm
npm install apitally@next
```

```shell yarn
yarn add apitally@next @opentelemetry/api
```

```shell pnpm
pnpm add apitally@next
```

```shell bun
bun add apitally@next
```
</CodeGroup>
