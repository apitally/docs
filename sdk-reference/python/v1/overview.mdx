## Requirements

Requires Python 3.10+.

## Installation

The Apitally SDK for Python uses extras to install the correct dependencies for each framework.

<CodeGroup>
```shell pip
pip install --pre "apitally[<your_framework>]"
```

```shell uv
uv add --prerelease allow "apitally[<your_framework>]"
```

```shell poetry
poetry add --allow-prereleases "apitally[<your_framework>]"
```
</CodeGroup>

Replace the `<your_framework>` placeholder with the extra for your framework. The options are:

- `blacksheep`
- `django`
- `fastapi`
- `flask`
- `litestar`
- `starlette`
